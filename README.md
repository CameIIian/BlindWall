# Blind-Wall for VRC

## Overview
Blind-wall for VRC game worlds.
We can't guarantee any issues arising during use.
Please obtain permission from those around you before using it.

## Dependencies
- `Modular Avatar`: <= 1.16.0
- `lilToon`: <= 2.3.2

## Action Verification
This project was created on Linux and tested in the Proton environment's VRC.

## Installation
1. import `Modular Avatar` & `liltoon`
2. import `BlindWall.unitypackage`
3. add `BlindWall.prefab` to your avatar
4. set `Source Transform` of `BlindWall` > `World_Position` > `Element_0` to Body.
5. uncheck `is_Active` and set `World_Position` > `Transform` > `positions` to 0.
6. push `Active` Button
7. upload

## Usage
After turning on the gimmick, use World Fix at the location you want to lock.
